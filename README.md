# DoNote  
**Organize your tasks and notes effortlessly.**

DoNote is a minimalist Android app built entirely with **Jetpack Compose**. It helps users stay organized by combining tasks and notes in one clean, distraction-free space.

## 🚀 Features
- Create, edit, and manage tasks with completion tracking
- Write and organize notes with titles
- Offline access to tasks and notes
- Clean, responsive, and minimalist UI using **Jetpack Compose**
- MVVM architecture with modern Android best practices

## 🛠️ Tech Stack
- **Kotlin**
- **Jetpack Compose**
- **Material 3 Design**
- **MVVM Architecture**
- **Room Database**
- **StateFlow**
- **LiveData (where needed)**
- **Coroutines + Flows**
- **ViewModel**
- **Navigation Compose**
- **Dependency Injection Ready (Hilt-optional structure)**
- **Offline-first Local Persistence**
- **Modular, Clean Code Structure**
